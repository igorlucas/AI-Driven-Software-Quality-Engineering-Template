# AI-assisted test design

Create a design record for each criterion or cohesive set of criteria. The purpose is to expose blind spots before choosing implementation: positive, negative, boundary, exploratory, security, and performance scenarios as applicable.

Use [template.md](template.md) and [the test design prompt](../ai/prompts/test-design.md). Link implemented `TEST` records and execution `EVID` records in `traceability/records.json`. A proposed scenario is not test coverage until implemented or deliberately performed and its result is recorded.
