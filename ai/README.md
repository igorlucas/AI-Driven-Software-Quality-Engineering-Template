# AI collaboration

Prompts under `prompts/` standardize drafts across the lifecycle. Provide only authorized, minimized context. Do not send secrets, credentials, personal/customer data, or confidential repository material to an AI service unless that service is approved for the data.

Treat all generated analysis as a hypothesis: preserve source IDs, cite supplied evidence, separate facts from assumptions, and require a named human to verify decisions and findings. Never let prompt output update a release, risk acceptance, incident record, or production system without review.
